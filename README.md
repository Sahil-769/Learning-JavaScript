## Practice & Notes

- **Core JavaScript:** variables, conditionals, loops, strings, arrays, functions, and array methods
- **DOM:** element selection, events, attributes, styles, and dynamic elements
- **Asynchronous JavaScript:** callbacks, promises, async/await, and Fetch API
- **Object-oriented JavaScript:** objects, classes, inheritance, `try/catch`, and prototypes
- **Namaste JavaScript:** high-order functions, `map`, `filter`, `reduce`, and event-loop examples

## Run Locally

Open any `index.html` file in a browser, or serve the repository with a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
